# claseJS10

Entregable

Objetivo
Planificar la conexión técnica entre tu lógica de JavaScript, una API externa/JSON local y una librería de apoyo, documentando el flujo de datos.

Instrucciones
Define tu Fuente de Datos: Captura los datos desde un api y/o un archivo JSON local que simule ser tu base de datos.
Captura de la información: Se debe consumir la información mediante un fetch, trabajando con la estructura async/await y try-catch.finally para el manejo de errores. Es fundamental que el usuario tenga comunicación en todo momento, el manejo de errores es muy importante.
Implementación de librerías: Implementar una librería de las vistas en el modulo para mejorar la comunicación de acciones con el usuario.
​

Entrega:
Sube tus archivos a un repositorio de GitHub y comparte la URL. Asegúrate de que el repositorio sea público para que pueda ser revisado.
